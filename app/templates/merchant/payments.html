Connecter Stripe Connexion externe

  1. Créez ou ouvrez votre compte Stripe. L'ouverture du compte, la vérification d'identité et l'IBAN se font chez Stripe : la plateforme ne peut pas les faire à votre place.
  2. Activez dans Stripe les moyens de paiement voulus (carte, Bancontact pour la Belgique, PayPal si disponible sur votre compte…).
  3. Créez une clé restreinte (rk_…) ou utilisez la clé secrète du mode voulu.
  4. Ajoutez un endpoint webhook vers {{ webhook_url }} avec les événements checkout.session.completed, checkout.session.async_payment_succeeded, checkout.session.async_payment_failed, checkout.session.expired, payment_intent.payment_failed, refund.updated, puis copiez le secret whsec_….
